🔷 🟡 Level 2: Joins (VERY IMPORTANT)

This is where most interviews focus.

1. Get employee name with department name (INNER JOIN)
     select e.emp_name,d.dept_name
     from employee e
     left join department d
     on e.dept_id = d.dept_id;

2. List all employees and their manager names (SELF JOIN)
	 select e.emp_name,d.emp_name
	 from employee e
	 inner join employee d
	 on e.manager_id = d.emp_id;

3. Show employees along with projects they are working on

Normal:
select e.emp_name,temp.project_name
from employee e
left join (
	select ep.emp_id,ep.project_id,p.project_name
	from employee_project ep
	left join project p
	on ep.project_id = p.project_id
) as temp
on e.emp_id = temp.emp_id;


Optimized:
SELECT e.emp_name, p.project_name
FROM employee e
LEFT JOIN employee_project ep
    ON e.emp_id = ep.emp_id
LEFT JOIN project p
    ON ep.project_id = p.project_id;


4. Find all employees who are not assigned to any project (LEFT JOIN)
	 select e.emp_name
	 from employee e
	 left join employee_project ep
	 on e.emp_id = ep.emp_id
	 where ep.project_id is null;

5. List all projects with employee count working on them

select *
from project p
left join employee_project ep
on p.project_id = ep.project_id;

If we want project name then:

Normal:
	 select p.project_name, tmp.count
	 from(
		 select project_id,count(emp_id) as count
		 from employee_project
		 group by project_id
	 ) as tmp
	 left join project p
	 on tmp.project_id = p.project_id;

Optimal:

select p.project_name,count(ep.emp_id)
from project p
left join employee_project ep
on p.project_id = ep.project_id
group by p.project_id,p.project_name;

🔷 🔥 Level 6: Very Advanced (Top-tier interviews)
***If you can solve these, you're strong.
1. Find employees who share the same salary in same department

    SELECT e.emp_name AS employee1,
           f.emp_name AS employee2,
           e.salary,
           e.dept_id
    FROM employee e
    JOIN employee f
    ON e.salary = f.salary
    AND e.dept_id = f.dept_id
    WHERE e.emp_id < f.emp_id;

Find duplicate salaries

3. Find employees whose salary is above department average

4. Find departments where no employee earns less than 30,000

5. Find employees who work on at least 2 projects AND earn > 50k

    SELECT e.emp_id,
           e.emp_name,
           COUNT(ep.project_id) AS project_count
    FROM employee e
    JOIN employee_project ep
    ON e.emp_id = ep.emp_id
    WHERE e.salary > 50000
    GROUP BY e.emp_id, e.emp_name
    HAVING COUNT(ep.project_id) >= 2;
